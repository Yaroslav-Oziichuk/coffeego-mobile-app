# Мобільний додаток «CoffeeGo»

## Опис проєкту
Система попереднього замовлення напоїв та їжі для мережі кав'ярень «CoffeeGo» з метою скорочення ранкових черг.

* **Тип системи**: Mobile (iOS & Android) + Backend API + Web-панель для менеджера/баристи.
* **Ключовий функціонал**: Попереднє замовлення напоїв, пуш-сповіщення про готовність, програма лояльності (бонуси), інтеграція з POS-системою кав'ярні.
* **Дедлайн**: 1 грудня.
* **Команда**: Backend-розробник, Mobile-розробник, UI/UX дизайнер, QA-інженер.
